# NARU BOARD — 나루 데이터베이스 기반 게시판

남월보드(Firebase)를 나루(naru.pub) SDK **1.1.0** 기반으로 재구축한 버전입니다.
사이트 테이블(SQLite) + 쿼리/뮤테이션으로 동작하므로 **제어판에서 컬렉션을 만들 필요가 없고**,
권한 검증(작성자 본인 확인·비밀글·비공개 게시판)이 전부 서버에서 강제됩니다.

## 설치

### 1. 파일 업로드
이 폴더의 내용 전체를 나루 사이트의 파일 관리에 업로드합니다.
`_naru/` 폴더(마이그레이션·쿼리·뮤테이션)가 꼭 포함되어야 합니다 —
업로드하면 나루가 자동으로 테이블을 만들고 코드를 배포합니다.

### 2. 사이트 회원 켜기 (제어판)
제어판 → 사이트 회원에서 가입 정책을 고릅니다.
(누구나 가입 / 운영자 승인 후 이용 / 신규 가입 중단, 이메일 인증 여부)

### 3. 관리자 로그인 등록 (제어판)
제어판의 '웹사이트 관리자 로그인'에 관리자 페이지 주소(예: `https://내사이트.naru.pub/`)를
등록합니다. 컬렉션은 선택하지 않아도 됩니다(모든 관리가 뮤테이션으로 이루어짐).

### 4. 첫 설정
`admin.html` 접속 → 관리자 로그인 → 사이트 제목·소개글 저장 → 게시판 추가.

## 회원 기능

- 방문자는 **나루 계정으로 로그인**해 이 사이트의 회원이 됩니다. (나루 아이디·이메일은 사이트에 전달되지 않음)
- 첫 글·댓글 전에 **닉네임을 등록**합니다. (사이트 안에서만 쓰는 이름, 중복 불가)
- 게시판 옵션 **'회원 글쓰기'**를 켜면 회원이 그 게시판에 글을 쓸 수 있습니다. (이미지 업로드 포함)
- 댓글·방명록은 회원/게스트 모두 작성 가능 — 게스트는 이름+비밀번호(선택)로 쓰고, 비밀번호가 있으면 직접 삭제할 수 있습니다.
- 타래(THREAD) 댓글은 **이미지 첨부** 가능(회원·관리자만, Ctrl+V 붙여넣기, 최대 8장, 1400px WebP 자동 리사이즈).
- **자기 글만 수정·삭제** — 서버 뮤테이션이 작성자를 확인하므로 우회할 수 없습니다.
- 회원 승인·차단은 나루 제어판의 '사이트 회원'에서 관리합니다.
  (운영진 같은 역할은 나루가 보관하지 않으므로, 필요해지면 사이트 테이블로 구현합니다 — 로드맵)

## 구조

```
index.html            홈 (소개글 + 최근 업데이트)
board.html?bo=ID      게시판 (스킨: BOARD / GALLERY / THREAD / LOG / GUESTBOOK)
view.html?id=&bo=     게시물 상세 + 댓글
write.html            글쓰기·수정 (관리자 / 회원 글쓰기 게시판의 회원)
admin.html            관리자 (사이트 설정 · 게시판 관리)
_naru/migrations/     테이블 정의 (업로드 시 자동 적용)
_naru/queries/        읽기 쿼리 (site:boot, board:posts·post·comments·guestbook·recent…)
_naru/mutations/      쓰기 뮤테이션 (account:register, post:write·remove, comment:…, site:…)
assets/js/core/       naru-client(SDK 래퍼) · site(부트스트랩·헤더) · config(NARU_SITE)
assets/js/shared/     sanitizer · comments · skins
assets/js/pages/      페이지별 스크립트
```

데이터는 전부 사이트 테이블에 저장됩니다:
`settings`(사이트 설정) · `boards`(게시판) · `profiles`(회원 닉네임) · `posts` · `comments` · `guestbook`

## Firebase판과 다른 점

- **관리자 = 나루 사이트 소유자 로그인** 하나입니다. (운영진 권한은 역할 테이블로 추후 확장 예정)
- **게스트 코드 시스템 → 회원 가입**으로 대체. 가입 정책(승인제 등)은 나루 제어판에서 정합니다.
- **비밀글이 진짜로 보호됩니다** — 비밀번호 확인과 본문 공개를 서버가 처리하므로,
  Firebase판의 소프트 잠금과 달리 API로도 내용을 읽을 수 없습니다.
- 회원 이미지 업로드는 시간당 30개, 파일 25 MiB, 사이트 미디어 250 MiB (나루 기준).
- 뮤테이션 호출 한도: 회원 분당 30번 · 방문자 주소당 분당 20번 · 사이트 전체 분당 300번.

> ⚠️ SDK 1.1.0은 나루의 개발 버전이라 세부 동작이 바뀔 수 있습니다.

## 로컬 테스트

나루 공식 로컬 개발 서버 [naru-dev](https://naru.pub/docs/dev)로 서버 코드(`_naru/`)까지
통째로 로컬에서 돌려볼 수 있습니다:

```
npx @naru-pub/dev . --site 내사이트명
```

(단순히 정적 서버로만 열 때는 `assets/js/core/config.js`의 `NARU_SITE`를 채우면
페이지는 뜨지만 `_naru/` 코드는 실제 나루 사이트에 업로드된 것이 실행됩니다.)

테이블 내용은 나루 제어판 → 데이터베이스 → 테이블에서 볼 수 있고,
그 아래 SQL 조회에서 SELECT 문을 직접 실행할 수도 있습니다.

## 스킨

| 스킨 | 형태 | 옵션 |
|---|---|---|
| BOARD | 제목+작성자+날짜 목록 | — |
| GALLERY | 썸네일 카드 그리드 | 컬럼 수(1~4) |
| THREAD | 카드 목록 + 좌(제목·썸네일)/우(본문 스크롤) 분할 상세, 댓글이 본문에 쌓임 | 컬럼 수 · 댓글 위치(하단/좌측) · 상세 썸네일 |
| LOG | 피드형 — 글마다 본문·댓글이 목록에 펼쳐짐 | — |
| GUESTBOOK | 방명록 | — |

## 로드맵 (미구현)

- PROFILE 스킨 이식
- 운영진(staff) 역할 — 댓글·글 관리 권한 위임
- 디자인 관리 (색·폰트)
- Firebase → 나루 데이터 이사 도구
- SCRIPT(플레이 로그) 스킨 — 아카이브를 미디어(텍스트 파일)로 저장
- 실시간 댓글 (subscribe 활용) · 새 댓글 앱 알림 (ctx.notify)
