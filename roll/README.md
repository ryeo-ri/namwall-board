# pancake-roll

이미지 아카이브 사이트 (naru.pub 정적 호스팅 + naru DB/SDK 1.0.0 기반)

관리자가 이미지 게시물을 등록하고, 게시물별 링크를 공유하면 누구나 볼 수 있습니다.
공개 목록 페이지는 없으며 링크로만 접근합니다. 애니메이션 효과는 전혀 사용하지 않습니다.

## 페이지

| 파일 | 설명 |
|---|---|
| `index.html` | 미니멀 랜딩 페이지 |
| `post.html?id=문서ID` | 게시물 뷰어 (방문자용, 공유 링크) |
| `admin.html` | 관리자 페이지 (게시물 등록/수정/삭제) |

## 게시물 형식

- **스크롤형**: 이미지를 세로로 이어서 표시
- **페이지형**: 이미지 1장씩 표시, 클릭하면 다음 장 (마지막 장에서 처음으로 순환, ←/→ 키 지원)
- 게시물마다 **배경색**과 **BGM(유튜브 링크)** 지정 가능 — BGM은 뷰어 하단 소형 플레이어로 표시

## naru.pub 설정 (최초 1회)

1. **사이트 이름 확인**: 사이트 주소가 `https://<이름>.naru.pub`이 아니라면 [js/config.js](js/config.js)의 `SITE` 값을 실제 로그인 이름으로 수정
2. **컬렉션 생성**: 제어판에서 `posts` 컬렉션을 만들고 권한 설정
   - 읽기: **누구나** (링크 공유 방식이므로)
   - 쓰기: **관리자만**
3. **관리자 로그인 등록**: 제어판의 '웹사이트 관리자 로그인'에
   - 페이지 주소: 배포된 `admin.html`의 주소 (예: `https://<이름>.naru.pub/admin.html`)
   - 컬렉션: `posts`

## 데이터 구조 (`posts` 컬렉션 문서)

```json
{
  "title": "게시물 제목",
  "type": "scroll",
  "bgm": "https://www.youtube.com/watch?v=...",
  "bgColor": "#ffffff",
  "images": [{ "url": "https://...", "name": "원본파일명.png" }]
}
```

- `type`: `"scroll"` | `"page"`
- `bgm`: 유튜브 링크, 없으면 `null`
- 이미지 파일은 관리자 페이지에서 `media.upload`로 올라가고 URL만 문서에 저장됨

## 로컬 미리보기

```bash
python -m http.server 4173
```

`http://localhost:4173` 접속. 로컬에서도 공개 읽기는 동작하지만, 관리자 로그인은 제어판에 등록된 주소에서만 가능합니다.

## 배포

이 저장소의 파일 전체(`index.html`, `post.html`, `admin.html`, `css/`, `js/`)를 naru.pub 사이트에 업로드합니다.
