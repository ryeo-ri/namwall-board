# NAMWALL Edition — 나루용 게시판 템플릿

[나루(naru.pub)](https://naru.pub)의 데이터베이스 기능으로 동작하는 개인 홈페이지용 게시판입니다.
빌드 없이 파일을 그대로 올려 쓰고, 글·댓글·설정은 모두 사이트 데이터베이스에 저장됩니다.
권한 확인(작성자 본인·비밀글·비공개 게시판)은 전부 서버 코드(`_naru/`)가 합니다.

현재 버전: **1.1.0** ([변경 내역](CHANGELOG.md))

## 기능

- **스킨 8종** — 게시판마다 고릅니다.

  | 스킨 | 형태 |
  |---|---|
  | BOARD |  목록형 일반 게시판. 일기, 로그 백업 등에 사용할 수 있습니다. |
  | GALLERY | 카드형 갤러리 게시판 (이미지·영상·텍스트) |
  | LOG | 로그 게시판. 이미지, 외부 이미지 URL, 영상업로드 등을 지원 합니다. <br> 로그호출 방법 #로그번호<br>링크걸기 방법 [제목]링크주소|
  | THREAD | 리뷰용 타래 게시판 |
  | GUESTBOOK | 방명록 게시판 |
  | SCRIPT | TRPG 플레이 로그 백업 (Roll20·코코포리아 로그 가져오기, 아카이브 뷰어) <br>백업게시판 사용법 https://tobe.aladin.co.kr/n/646421 |
  | PROFILE | 캐릭터 프로필 게시판 |
  | BOOKMARK | 배너 북마크 |

- **회원·게스트** — 방문자는 나루 계정으로 로그인해 사이트 회원이 되고, 닉네임을 등록해 글·댓글을 씁니다.
  게스트는 이름과 비밀번호(선택)로 댓글·방명록을 남깁니다.
- **댓글** — 답글, 비밀 댓글, 접기, 이미지 첨부(회원), 유튜브·`#로그번호`·`[제목]링크` 표기.
- **글** — 비밀글, 회원 공개, 분류, 태그, 대표 이미지/영상, 추가 이미지, 검색(제목·본문·출처·태그·댓글).
- **관리자 화면** — 홈 소개(대표 이미지·소개 글·하단 메뉴), 게시판 생성·순서 변경, 디자인(색·폰트·배경 이미지).

## 필요한 것

- 나루 계정과 **서포터 플랜의 데이터베이스 기능**
- 사이트 코드(`_naru/`)가 들어 있어 **사이트 전체(/)에만** 적용할 수 있습니다.

## 설치

### 템플릿으로 적용
나루 템플릿 스토어에서 이 템플릿을 골라 '내 사이트에 적용' → '사이트 전체(/)'를 선택합니다.
테이블은 적용할 때 자동으로 만들어집니다.

### 직접 올리기
이 저장소의 `site/` 폴더 **안의 내용**을 사이트 최상위에 그대로 올립니다. `_naru/` 폴더가 꼭 포함되어야 합니다.

### 첫 설정
1. 제어판 → **사이트 회원**에서 가입 정책을 고릅니다. (누구나 가입 / 승인 후 이용 / 가입 중단)
2. 제어판의 **웹사이트 관리자 로그인**에 사이트 주소(예: `https://내사이트.naru.pub/`)를 등록합니다. 컬렉션은 고르지 않아도 됩니다.
3. `admin.html`에 접속해 관리자로 로그인합니다.
4. **홈 소개 관리**에서 사이트 제목을 저장하고, **게시판/메뉴 통합 관리**에서 게시판을 만듭니다.
5. 관리자 대시보드의 **글쓰기 계정 연결**에서 회원 계정을 관리자로 연결하면, 관리자 페이지 밖에서도 관리자로 글을 쓰고 관리할 수 있습니다.

## 내 것으로 고치기

템플릿 파일을 직접 고치면 업데이트할 때 그 파일이 `/.backup/`으로 옮겨지고 새 파일로 바뀝니다.
바꾸고 싶은 것은 아래 두 곳에 두세요. 업데이트해도 그대로 남습니다.

- **관리자 화면의 설정** — 사이트 제목, 홈 소개, 게시판, 색·폰트·배경은 데이터베이스에 저장됩니다.
- **`/_owner/` 폴더** — 관리자 → 디자인 관리에서 **'/_owner/ 파일 불러오기'**를 켜면, 사용자 페이지가
  `/_owner/style.css`와 `/_owner/script.js`를 템플릿의 스타일·스크립트 뒤에 불러옵니다.
  파일 편집기에서 두 파일을 만들어 내 CSS와 자바스크립트를 넣으세요. (관리자 페이지에는 적용되지 않습니다.)

## 업데이트

새 버전이 나오면 나루가 알려 줍니다. '바뀌는 파일 보기'로 확인한 뒤 업데이트하세요.

- 글·댓글·설정(데이터베이스)과 `/_owner/` 폴더는 그대로입니다.
- 테이블 구조가 바뀌는 버전은 마이그레이션이 자동으로 적용됩니다.
- 화면이 바로 바뀌지 않으면 새로고침을 한두 번 하세요. (정적 파일을 서비스 워커가 캐시합니다.)
- 지금 버전은 관리자 대시보드에서 볼 수 있습니다.

## 구조

```
site/
  index.html            홈
  board.html?bo=ID      게시판 목록
  view.html?id=&bo=     글 상세 + 댓글
  write.html            글쓰기·수정
  search.html           검색
  admin.html            관리자 (홈 소개 · 게시판 · 디자인)
  sw.js                 서비스 워커 (정적 파일 캐시)
  assets/css/           style.css
  assets/js/core/       나루 SDK 래퍼 · 사이트 공통 · 설정(config.js) · 버전
  assets/js/shared/     여러 페이지가 쓰는 모듈 (댓글 · 정제기 · 디자인 …)
  assets/js/skins/      스킨별 렌더러
  assets/js/pages/      페이지별 진입 스크립트
  _naru/migrations/     테이블 정의 (자동 적용)
  _naru/queries/        읽기 쿼리
  _naru/mutations/      쓰기 뮤테이션
  _naru/modules/        서버 공통 모듈
```

데이터는 사이트 테이블에 저장됩니다:
`settings`(사이트 설정) · `boards` · `profiles`(회원 닉네임) · `posts` · `comments` · `guestbook`

## 알아둘 한도 (나루 기준)

- 회원 이미지 업로드: 시간당 30개, 파일당 25 MiB
- 뮤테이션 호출: 회원 분당 30번 · 방문자 주소당 분당 20번
- 나루 SDK **1.1.0** 기준으로 만들었습니다. SDK가 바뀌면 세부 동작이 달라질 수 있습니다.

## 로컬에서 돌려 보기

나루 로컬 개발 서버 [naru-dev](https://naru.pub/docs/dev)로 서버 코드까지 내 컴퓨터에서 돌릴 수 있습니다.

```
npx @naru-pub/dev ./site --site demo
```

정적 서버로만 열 때는 `site/assets/js/core/config.js`의 `NARU_SITE`에 사이트 이름을 넣어야 합니다.
(`<사이트명>.naru.pub`에 올려 쓰면 비워 둬도 됩니다.)
