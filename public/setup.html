FIRST‑RUN SETUP

사이트 첫 설정

첫 관리자가 등록되면 이 화면은 사라지고 홈이 활성화됩니다. 아래 순서대로 진행하세요.

1. Firebase 준비 콘솔에서 클릭만
  1. Firebase 콘솔에서 프로젝트 생성
  2. 빌드 → Authentication → 시작하기 → 이메일/비밀번호 사용 설정
  3. 빌드 → Firestore Database → 데이터베이스 만들기
    • 위치(리전): asia-northeast3 (서울) 선택 — 한국 이용자면 서울이 가장 빠릅니다. 한 번 정하면 변경할 수 없으니 서울로 지정하세요.
    • 모드: 프로덕션 모드로 시작을 선택(보안 규칙은 5단계에서 붙여넣습니다). "테스트 모드"는 30일 뒤 자동으로 잠기므로 권장하지 않습니다.
    • 만들기를 눌러 완료합니다.
  4. 빌드 → Storage → 시작하기 (위치는 Firestore와 동일하게 서울)
  5. Firestore → 규칙 탭에 프로젝트의 firestore.rules 내용을 붙여넣고 게시. Storage → 규칙도 storage.rules로 동일하게
  6. 프로젝트 설정 → 웹 앱 추가에서 나오는 firebaseConfig를 복사
복사한 firebaseConfig를 assets/js/core/firebase.js 상단 값과 교체한 뒤 사이트를 다시 업로드하세요. 이 값은 모든 방문자가 공유하므로 브라우저 입력이 아니라 파일에 넣어야 합니다.
