FIRST‑RUN SETUP

사이트 첫 설정

첫 관리자가 등록되면 이 화면은 사라지고 홈이 활성화됩니다. 아래 순서대로 진행하세요.

1. Firebase 준비 Firebase 콘솔 바로가기

새 프로젝트 만들기 → 프로젝트 이름 입력 → 프로젝트 생성

좌측메뉴에서 설정해야 할 것이 3가지 있습니다.

  1. 데이터베이스 및 스토리지 → Firestore → 데이터베이스 만들기
    • 위치(리전): asia-northeast3 (서울) 선택 — 다른 지역을 선택하여도 괜찮으나 가까운 지역으로 하는 것이 좋습니다. 한 번 정하면 변경할 수 없으니 주의.
    • 모드: 프로덕션 모드로 시작을 선택(보안 규칙은 아래에서 붙여넣습니다). "테스트 모드"는 30일 뒤 자동으로 잠기므로 권장하지 않음.
    • 만들기를 눌러 완료합니다.
    • Firestore → 규칙 탭에 프로젝트의 firestore.rules 내용을 붙여넣고 게시.
  2. 데이터베이스 및 스토리지 → Storage → 시작하기
    • 모든 위치: asia-northeast3 (서울)
    • 해당 위치로 하더라도 무료기준을 넘지 않으면 무료로 이용할 수 있습니다. 개인홈페이지 용도로는 무료범위로 충분히 사용가능합니다!
    • 모드: 프로덕션 모드로 시작을 선택.
    • Storage → 규칙도 storage.rules 내용을 붙여넣고 게시.
  3. 보안 → Authentication → 시작하기 → 이메일/비밀번호 사용 설정
  4. 설정 → 일반 → 내 앱 → 웹 앱에 Firebase 추가
    • 웹 앱의 이름은 자유롭게 등록.
    • Firebase SDK 추가 하단에 나오는 코드 중 firebaseConfig를 복사.

파일 중 assets/js/core/firebase.js 수정.

const firebaseConfig = {
  apiKey:
  authDomain:
  projectId:
  storageBucket:
  messagingSenderId:
  appId:
};
firebaseConfig 값을 복사한 값으로 교체한 뒤 다시 업로드 해주세요. 창을 새로고침 하여 하단의 연결 상태를 확인합니다.
