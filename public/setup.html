FIRST‑RUN SETUP

사이트 첫 설정

첫 관리자가 등록되면 이 화면은 사라지고 홈이 활성화됩니다. 아래 순서대로 진행하세요.

1. Firebase 준비 Firebase 콘솔 바로가기

새 프로젝트 만들기 → 프로젝트 이름 입력 → 프로젝트 생성

좌측메뉴에서 설정해야 할 것이 3가지 있습니다.

  1. 데이터베이스 및 스토리지 → Firestore → 데이터베이스 만들기
    • 위치(리전): asia-northeast3 (서울) 선택 — 다른 지역을 선택하여도 괜찮으나 가까운 지역으로 하는 것이 좋습니다. 한 번 정하면 변경할 수 없으니 주의.
    • 모드: 프로덕션 모드로 시작을 선택(보안 규칙은 나중에 설정합니다.) 테스트 모드는 30일 뒤 자동으로 잠기므로 권장하지 않음.
    • 만들기를 눌러 완료합니다.
    • Firestore → 규칙 탭에 프로젝트의 firestore.rules 내용을 붙여넣고 게시.
    • Firestore → 인덱스 탭에서 인덱스 추가를 눌러 아래 복합 인덱스 4개를 만듭니다.
      • 게시판 조회용 — 컬렉션 ID: posts / 쿼리 범위: 컬렉션 / boardId 오름차순 + isPublic 오름차순
      • 최근 업데이트용 — 컬렉션 ID: posts / 쿼리 범위: 컬렉션 / isPublic 오름차순 + updatedAt 내림차순
      • 최근 업데이트용 — 컬렉션 ID: posts / 쿼리 범위: 컬렉션 / isPublic 오름차순 + createdAt 내림차순
      • 최근 업데이트용 — 컬렉션 ID: posts / 쿼리 범위: 컬렉션 / isPublic 오름차순 + contentUpdatedAt 내림차순
      • CLI로 자동 추가: 프로젝트 폴더에서 firebase deploy --only firestore:indexes를 실행하면 firestore.indexes.json의 인덱스가 한 번에 등록됩니다.
      • 수동 추가: Firebase 콘솔에서 위 항목을 하나씩 만든 뒤, 네 인덱스의 상태가 모두 사용 설정됨으로 바뀔 때까지 기다립니다. 생성에는 몇 분 정도 걸릴 수 있습니다.
  2. 데이터베이스 및 스토리지 → Storage → 시작하기
    • 모든 위치: asia-northeast3 (서울)
    • 해당 위치로 하더라도 무료기준을 넘지 않으면 청구되지 않습니다. 개인홈페이지 용도로는 무료범위로 충분히 사용가능합니다!
    • 모드: 프로덕션 모드로 시작을 선택.
    • Storage → 규칙도 storage.rules 내용을 붙여넣고 게시.
  3. 보안 → Authentication → 시작하기 → 이메일/비밀번호 사용 설정
설정 → 일반 → 내 앱 → 웹 앱에 Firebase 추가

웹 앱의 이름은 자유롭게 등록.

Firebase SDK 추가 하단에 나오는 코드 중 firebaseConfig를 복사.

assets/js/core/firebase.js 파일 수정.

const firebaseConfig = {
  apiKey:
  authDomain:
  projectId:
  storageBucket:
  messagingSenderId:
  appId:
};
firebaseConfig 값을 복사한 값으로 교체한 뒤 다시 업로드 해주세요. 창을 새로고침 하여 하단의 연결 상태를 확인합니다.
