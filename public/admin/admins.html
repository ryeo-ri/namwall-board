관리자 프로필 목록

Auth 계정 생성은 Firebase Console/Auth에서 수행하고, 여기서는 admin_users 프로필을 추가/수정합니다.

Auth 계정 생성 가이드
  1. Firebase Console에서 Authentication → Users로 이동해 사용자 추가(이메일·비밀번호)로 계정을 만듭니다.
  2. 생성된 계정의 UID를 복사합니다.
  3. 아래 폼에 UID·닉네임을 입력하고 관리자 프로필 저장을 누르면 admin_users 문서가 생성되어 관리자 권한이 부여됩니다.
  4. 그 계정으로 관리자 로그인 하면 됩니다.
